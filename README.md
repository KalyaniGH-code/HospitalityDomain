# HospitalityDomain
The project aims to help hotel management teams make informed decisions by visualizing trends and patterns in hotel revenue, occupancy rates, and customer behavior.

# Key Features:
► Revenue & Occupancy Analysis – Monitor overall revenue performance, occupancy rates, and guest behavior trends over time.
► Booking and Cancellation Insights – Gain visibility into booking patterns and cancellation metrics by hotel and distribution channel.
► City-wise Revenue Distribution – Assess revenue contributions across locations to identify high-performing cities.
► Channel Performance Evaluation – Compare direct bookings with third-party platforms (OTAs) to refine distribution strategies.
► Interactive Filtering Capabilities – Seamlessly explore data across various time frames, properties, and dimensions.
